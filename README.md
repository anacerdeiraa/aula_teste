\# 🚀 Primeira Atividade com Git



Este repositório foi criado como parte da minha \*\*primeira atividade prática utilizando Git e GitHub\*\*.  

O objetivo é aprender os conceitos básicos de controle de versão e realizar as configurações iniciais do Git no computador.



\## 📌 Objetivos da atividade



\- Instalar o \*\*Git\*\*

\- Configurar as informações do usuário

\- Criar um repositório local

\- Conectar o repositório ao \*\*GitHub\*\*

\- Realizar o primeiro commit

\- Enviar arquivos para o repositório remoto



\## ⚙️ Configurações iniciais do Git



Para começar a utilizar o Git, foram feitas as seguintes configurações no terminal:



```bash

git config --global user.name "Seu Nome"

git config --global user.email "seuemail@email.com"
